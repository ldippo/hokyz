# Game contract

Derived from current code and ROADMAP-v2/v3, not a new product decision.

Arcade hockey with readable puck action, forceful hits, on-fire spectacle, and
meaningful roster/perk choices between matches. Keep both skill expression and
first-session approachability. Local co-op was deferred in the existing roadmap.

Protect seeded runs, finite matches, saves and unlocks, keyboard/gamepad navigation,
remapped prompts, colorblind cues, and reduced motion. A balance gain that obscures
the puck or makes controls harder to learn is not automatically an improvement.

No new milestone is selected: v3 is recorded complete and v4 is empty. Plan new
work from the user's requested outcome and verify historical claims against code.
