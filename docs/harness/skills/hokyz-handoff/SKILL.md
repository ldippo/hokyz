---
name: hokyz-handoff
description: Save or resume Hokyz development progress with task state, evidence paths, failures, and a precise next action. Use for a Hokyz handoff or resuming its gaming loop.
---

For saving, update `docs/handoffs/current.md` with the active goal, scope, queue ID,
completed work, changed files, commands and results, evidence paths, open failures,
and next action. Link the burst report and original deadline when one is active.
Keep reusable decisions in CONTEXT/design docs rather than duplicating them here.

For resuming, read the handoff and referenced task/report, inspect actual files and
Git status, and verify the evidence still applies. Resume the user's authorized
scope; an expired burst stays stopped. Do not replay completed work, treat historical
publishing notes as current authorization, or erase unrelated changes.
